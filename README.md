<div align="center">
  <samp>
    <b>
      About This Project
    </b>
  </samp>
  <br>
  <br>

  <samp>
    This is an interactive birthday website created as a digital gift for my best friend.
    <br><br>
    The entire experience was inspired by <b>OMORI</b>, our favorite game,
    mixing nostalgic visuals, handwritten aesthetics, secret interactions,
    and emotional storytelling into a personal memory archive.
    <br><br>
    More than just a webpage, the project was designed to feel like
    a playable scrapbook full of hidden details, conversations,
    achievements, timeline fragments, and little memories collected over the years.
  </samp>

</div>
